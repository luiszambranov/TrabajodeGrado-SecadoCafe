# /data

Datos de referencia y datasets generados.

- `reference/`  — datos/curvas de literatura usados para validar el modelo
  (p. ej. Phitakwinai, Thepa & Nilnont, 2019, secado de café pergamino).
- `simulations/` — datasets limpios generados por las campañas de simulación,
  con diccionario de variables.

Distinguir siempre datos simulados, datos de literatura y datos físicos propios.
