# /fluidsim

Circuito neumático de actuación (FluidSIM).

La actuación neumática debe modificar una variable físicamente interpretable de la
planta (p. ej. caudal de aire, apertura de compuerta, ruta de ventilación). No debe
quedar como una animación desconectada del modelo.

Entregable semana 6: circuito neumático funcional integrado con Python y CODESYS.
